01

Read what is there.

Inspect shot timing, visible words, subtitle appearance, coarse motion and signal cues. Keep timestamp evidence and the limits of coverage.

Extract the grammar.

Normalize supported caption, layout, entrance and rhythm decisions. Keep an explicit record of inferred choices and unknown originals.

Add new text and independent assets. Reflow and retime the new words. The reference is never an implicit footage or music fallback.

CLAUDE CODE / CODEX

Evidence before certainty.

A flattened video cannot uniquely reveal its hidden layers, original fonts, source clips, plugins or editing project. This release handles observable evidence and a bounded native 2D style vocabulary. Exact font recovery, arbitrary 3D/VFX, HDR and unrestricted NLE imports remain outside its verified scope. New words receive new timing; estimated timing is not ASR alignment.
