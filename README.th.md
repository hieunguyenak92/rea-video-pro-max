## เปลี่ยนวิดีโออ้างอิงให้เป็นงานที่ทำต่อได้

| สิ่งที่คุณต้องการทำ | ผลลัพธ์ที่ได้รับ |

| นำรูปแบบซับไปใช้กับเรื่องใหม่ | รูปแบบตัวอักษร การจัดวาง และพาเลตสีเน้นที่ใช้ซ้ำได้ โดยปรับเข้ากับคำใหม่และเวลาชุดใหม่ |
| สร้างรูปแบบวิดีโอสำหรับใช้งานต่อเนื่อง | เทมเพลตสไตล์ที่ผูกกับสคริปต์อื่นและชุดสื่ออื่นได้ |
| กำกับผลลัพธ์ด้วยตัวเอง | ไทม์ไลน์/โปรเจกต์ JSON แบบเนทีฟ พร้อมสำเนาสื่อและแฮช ให้ตรวจ แก้ และเรนเดอร์ใหม่ได้ |
| เชื่อมการวิเคราะห์เข้ากับระบบของคุณ | ไฟล์มีโครงสร้าง ตัวตรวจดูแบบออฟไลน์ การส่งออกซับ และการแลกเปลี่ยนไทม์ไลน์ภายในขอบเขตที่รองรับ |

## เริ่มเวิร์กโฟลว์ด้วยพรอมป์ต์เดียว

ติดตั้ง Skill ที่แนบมา ส่งวิดีโออ้างอิงและเนื้อหาใหม่ให้เอเจนต์ แล้วสั่งงานดังนี้

```text
Use REA-Video-Pro-Max to break down reference.mp4: shot rhythm,
subtitle layout, highlight colors and supported motion.
Extract a reusable style, then use my new script and assets to make
an original video with a similar editing language.
Render the video, keep the editable project, verify the new content,
and show me any effects that need an approximation.
```

คุณกำหนดเรื่องราว ส่วน Skill มอบขั้นตอนที่ชัดเจนและเครื่องมือที่รันได้จริงให้เอเจนต์ใช้วิเคราะห์ จัดองค์ประกอบ เรนเดอร์ และตรวจสอบ

## ความสามารถที่ช่วยให้งานเดินต่อได้จริง

- **งานตัดต่อที่ตามตรวจหลักฐานได้** ไทม์สแตมป์การแสดงผลที่ถอดรหัส หลักฐานเฟรม และขอบเขตการตรวจทำให้ติดตามไทม์ไลน์ได้ สัญญาณที่วัด ผลจากโมเดล และข้อสันนิษฐานด้านการตัดต่อจะมีป้ายกำกับแยกกัน
- **รายละเอียดซับที่ส่งต่อสู่ชิ้นงานใหม่ได้** ประเมินขนาด ตำแหน่ง สีเติม และเส้นขอบที่มองเห็น เก็บพาเลตสีเน้นและรูปแบบย่อยที่สังเกตได้แยกกัน แล้วจัดบรรทัดและเวลาของคำใหม่ระหว่างสร้างองค์ประกอบ
- **การเคลื่อนไหวที่รักษาทิศทาง** ฟิตแบบจำลอง similarity/affine และเส้นโค้งตามเวลาภายในขอบเขตที่กำหนด ตัวเรนเดอร์เนทีฟใช้ส่วนซูมแบบมีทิศทางที่รองรับซ้ำได้ รวมถึงซูมออก
- **โปรเจกต์ที่พัฒนาต่อได้** คัดลอกภาพ ฟุตเทจ ฟอนต์ และเสียงที่เลือกใช้ลงในโปรเจกต์ที่ย้ายไปมาได้ การผูกเนื้อหาอย่างชัดเจนและแฮชช่วยให้ตรวจสิ่งที่เลือกใช้ได้
- **ใช้เสียงเมื่อโจทย์ต้องการ** faster-whisper ASR แบบโลคัลเป็นตัวเลือกสำหรับสร้างช่วงเวลาระดับคำจากโมเดล การตรวจจับคู่สคริปต์/เสียงอย่างเข้มงวดช่วยผูกเวลานั้นกับเนื้อหาใหม่ ต้องจัดเตรียมโมเดลโลคัลอย่างชัดเจน
- **ผลลัพธ์ที่ตรวจสอบได้** ตรวจความตรงกันของโปรเจกต์/เอาต์พุต ถอดรหัสวิดีโอที่เรนเดอร์ และใช้ OCR แยกตรวจเนื้อหาซับ เก็บหลักฐานไว้กับผลงานได้

ตัวเรนเดอร์เนทีฟรองรับ **ซับ static / fade / pop / slide**, **ทรานซิชัน cut / dissolve / fade / wipe** และ **พื้นหลัง static / panzoom แบบมีทิศทาง** การวิเคราะห์อาจเก็บข้อสังเกตด้านการเคลื่อนไหวได้มากกว่าที่ตัวเรนเดอร์เนทีฟสร้างซ้ำได้ [ขอบเขตที่รองรับอย่างละเอียด (ภาษาอังกฤษ)](docs/SUPPORT-MATRIX.md)

## สร้างผลลัพธ์แรกของคุณ

### 1. เตรียมสภาพแวดล้อมรัน

ใช้ **Python 3.11+**, **FFmpeg + FFprobe** และ FFmpeg ที่มี **libx264** ติดตั้ง **Tesseract พร้อมข้อมูลภาษา `eng`** เพื่อรันตัวอย่าง OCR และการตรวจซับที่แนบมา ส่วนไลบรารี Python ติดตั้งด้วยคำสั่งด้านล่าง

```sh
git clone https://github.com/hieunguyenak92/rea-video-pro-max.git
cd rea-video-pro-max
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e .
rea-video-pro-max doctor
```

คำสั่งเชลล์นี้สำหรับ macOS/Linux CI ของรุ่นเผยแพร่ผ่านบน Linux และ macOS แล้ว ส่วนการเรนเดอร์เนทีฟบน Windows ยังไม่ได้รับการรับรอง `doctor` จะแสดงเครื่องมือที่ใช้ได้จริงบนเครื่องคุณ

### วิเคราะห์วิดีโอจาก URL สาธารณะโดยอัตโนมัติ

สำหรับหน้าวิดีโอสาธารณะของ YouTube, Facebook หรือ TikTok ที่คุณมีสิทธิ์ใช้งาน ให้ติดตั้งส่วนเสริมรับ URL แล้วให้ skill ดาวน์โหลดสำเนาในเครื่องที่มีขอบเขตก่อนวิเคราะห์:

```sh
python -m pip install 'rea-video-pro-max[url]'
rea-video-pro-max analyze-url 'https://www.youtube.com/shorts/VIDEO_ID' --out work/url-analysis --ocr required --ocr-lang eng
```

หากใช้ skill ZIP ที่แตกไฟล์แล้ว ให้ติดตั้ง `yt-dlp>=2025.01.15,<2027` โดยตรง ZIP จะไม่ติดตั้งการพึ่งพาเสริมโดยอัตโนมัติ

skill ZIP v0.1.1 ที่ลิงก์ด้านบนออกมาก่อนอะแดปเตอร์ URL เสริมนี้ ให้ใช้ checkout ปัจจุบันสำหรับการรับ URL จนกว่าจะมีรุ่นถัดไป

คำสั่งนี้บันทึกวิดีโอและ `url-source.json` ซึ่งมี URL, ตัวดึงข้อมูล, ระยะเวลา, จำนวนไบต์ และ SHA-256 จากนั้นสร้างผลวิเคราะห์ปกติไว้ใน `work/url-analysis/analysis/` จะไม่ใช้ข้อมูลเข้าสู่ระบบ ไม่หลบเลี่ยง DRM ไม่รับเพลย์ลิสต์/สตรีมสด และไม่ดาวน์โหลดน้ำหนักโมเดล สิทธิ์เข้าถึง แหล่งลิขสิทธิ์ และข้อกำหนดของแพลตฟอร์มยังเป็นความรับผิดชอบของคุณ [รายละเอียดการรับ URL (ภาษาอังกฤษ)](skills/rea-video-pro-max/references/url-ingestion.md)


### 3. รันตัวอย่าง A → B ที่แนบมา

```sh
rea-video-pro-max analyze examples/reference.mp4 --out work/analysis --ocr required --ocr-lang eng
rea-video-pro-max template work/analysis/analysis.json --out work/style-template.json
rea-video-pro-max compose work/style-template.json --content examples/content.json --out work/project
rea-video-pro-max render work/project/project.json --out work/video-b.mp4
rea-video-pro-max verify work/project/project.json --mode style-transfer --render work/video-b.mp4 --ocr-lang eng
```

เปิด `work/video-b.mp4` โปรเจกต์ที่ย้ายไปใช้ต่อได้อยู่ใน `work/project/` และผลวิเคราะห์วิดีโออ้างอิงอยู่ใน `work/analysis/` ใช้ไดเรกทอรีเอาต์พุตใหม่สำหรับการสร้างแต่ละครั้ง หากต้องการตัวตรวจดูการวิเคราะห์แบบออฟไลน์ ให้รัน

```sh
rea-video-pro-max report work/analysis/analysis.json --out work/report
```

จากนั้นเปิด `work/report/timeline.html` ในเครื่อง [CLI, Skill และ MCP แบบเลือกใช้ ใช้เคอร์เนลเดียวกัน (ภาษาอังกฤษ)](skills/rea-video-pro-max/references/runtime-and-support.md)

หลักฐานประกอบด้วยการรันซ้ำครบวงจร **A → วิเคราะห์ → สไตล์ → B ใหม่** ด้วยสื่อที่สร้างเอง งานภาษาเวียดนามที่ทดสอบแยกพร้อมแก้ตัวอักษร/เส้นขอบและตรวจรูปแบบเน้นสองแบบ และงานการเคลื่อนไหวที่รักษาทิศทางซูมเข้า/ออก กรณีเหล่านี้เป็นกรณีที่สร้างเองและจำกัดขอบเขต แสดงว่าเวิร์กโฟลว์ที่สาธิตทำงานได้ ไม่ใช่ผลวัดความแม่นยำครอบคลุมทุกแนววิดีโอหรือทุกภาษา

## เก็บผลลัพธ์ไว้ แล้วขยายระบบต่อ

| รูปแบบ | ข้อมูลที่บรรจุ |
| --- | --- |
| JSON เนทีฟ | ผลวิเคราะห์ ไทม์ไลน์ ข้อมูลซับ/สไตล์/การเคลื่อนไหว/เสียง เทมเพลต และโปรเจกต์เนทีฟที่แก้ไขได้ |
| CSV | แถวข้อมูลช็อตสำหรับตรวจและประมวลผลต่อ |
| SRT / WebVTT | ข้อความที่มองเห็นและช่วงเวลาคิว |
| ASS | เวลาซับพร้อมสไตล์ทดแทนที่ระบุชัดเจน รูปลักษณ์ที่สังเกตได้และความไม่แน่นอนยังเก็บอยู่ในหลักฐานเนทีฟ |
| OTIO / EDL | ส่วนอ้างอิง OTIO แบบเลือกใช้พร้อมคำอธิบาย และ EDL สำหรับคัตที่วัดได้ในวิดีโอ CFR เฟรมเรตจำนวนเต็ม บันทึกการส่งออกระบุข้อมูลที่สูญเสีย |
| MP4 + HTML ออฟไลน์ | วิดีโอใหม่และรายงานวิเคราะห์ที่ตรวจดูในเครื่องได้ |

โปรเจกต์เนทีฟเป็น JSON ที่แก้ไขได้ รุ่นนี้ไม่ส่งออกโปรเจกต์รูปแบบเนทีฟของ Premiere, Resolve, After Effects หรือ CapCut และไม่ส่งออก FCPXML การนำไฟล์รูปแบบแลกเปลี่ยนที่รองรับเข้าโปรแกรมตัดต่อภายนอกยังไม่ได้รับการตรวจสอบ [ขอบเขตการส่งออกและเรนเดอร์ (ภาษาอังกฤษ)](docs/SUPPORT-MATRIX.md)

## รู้ขอบเขตก่อนสร้างสรรค์

รุ่นปัจจุบันเน้นหลักฐานการตัดต่อที่สังเกตได้ และการใช้สไตล์ **2D** ที่รองรับซ้ำ ฟอนต์ต้นฉบับที่แน่นอน เลเยอร์ที่ซ่อน ปลั๊กอิน สื่อต้นทาง และประวัติโปรเจกต์อาจยังไม่ทราบ OCR และการฟิตการเคลื่อนไหวอาจผิดได้ ระบบแสดงขอบเขตการสุ่มตัวอย่างและความไม่แน่นอนไว้

ฟุตเทจที่ผูกเข้ามาต้องมีทิศทางถูกต้องและใช้พิกเซลสี่เหลี่ยมจัตุรัส เสียงของฟุตเทจในฉากจะถูกปิด จึงต้องระบุเสียงแยกอย่างชัดเจน ระบบอักษรซับซ้อนต้องมีฟอนต์และการจัดรูปอักษรที่เหมาะสม ซับแบบสองทิศทางจะถูกปฏิเสธ README เก้าภาษาอธิบายผลิตภัณฑ์ ไม่ได้หมายถึงการรับรอง OCR/เรนเดอร์เก้าภาษา การตัดสินสไตล์สร้างสรรค์และเสียงยังต้องมีคนตรวจ [ตารางขอบเขตทั้งหมด (ภาษาอังกฤษ)](docs/SUPPORT-MATRIX.md)

การประมวลผลหลักทำในเครื่อง ไม่ต้องใช้ API โมเดลแบบเสียเงินหรืออัปโหลดเนื้อหา การติดตั้งไลบรารีและโมเดลทางเลือกอาจต้องเชื่อมต่อเครือข่าย ส่วนโฮสต์ Claude/Codex มีนโยบายข้อมูลของตนเอง รายงานในเครื่องแนบสื่ออ้างอิงและภาพครอปโดยค่าเริ่มต้น `report --no-media` จะไม่แนบสำเนาวิดีโออ้างอิงทั้งไฟล์ แต่ยังเก็บข้อความและภาพครอป [ความเป็นส่วนตัว (ภาษาอังกฤษ)](docs/PRIVACY.md)
